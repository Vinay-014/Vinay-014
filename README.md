### 🧩 Design Philosophy

> I optimize for **resilience over convenience** and **auditability over black boxes**.

- Every critical path has a fallback (LLM routing, telephony, search providers)
- Facts are never deleted — they are superseded with lineage
- Plans are stress-tested adversarially before execution
- Observability is first-class (tracing, token cost, confidence scores)
- Evaluation harnesses ship with the product
